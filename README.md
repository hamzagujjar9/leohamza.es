# My portfolio

A fast, static portfolio site. No build step, no frameworks.

## Files
- `index.html` – all your content (name, about, projects, skills, contact)
- `style.css` – colors and layout
- `script.js` – light/dark switch and footer year
- `images/` – your photo and project images

## Edit
Open `index.html` and change the text. Comments in the file show what to copy or replace.

## Preview locally
Double-click `index.html`.

## Deploy
Hosted with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
